# Worked examples

Spreadsheet worked examples that show how each result table is calculated from sample
losses — useful for validating an implementation. They live in `Docs/WorkedExamples/` in
this repository:

| Example | Covers |
| --- | --- |

| [SPLT_MPLT_QPLT.xlsx](https://github.com/OasisLMF/ODS_OpenResultsData/blob/master/Docs/WorkedExamples/SPLT_MPLT_QPLT.xlsx) | Period loss tables — sample, moment and quantile |
| [SELT_SPLT.xlsx](https://github.com/OasisLMF/ODS_OpenResultsData/blob/master/Docs/WorkedExamples/SELT_SPLT.xlsx) | Relationship between event and period sample tables |
| [EPT_1_Mean_Damage.xlsx](https://github.com/OasisLMF/ODS_OpenResultsData/blob/master/Docs/WorkedExamples/EPT_1_Mean_Damage.xlsx) | Exceedance-probability table — mean damage (EPCalc 1) |
| [EPT_2_Full_Uncertainty.xlsx](https://github.com/OasisLMF/ODS_OpenResultsData/blob/master/Docs/WorkedExamples/EPT_2_Full_Uncertainty.xlsx) | EPT — full uncertainty (EPCalc 2) |

| [TVAR.xlsx](https://github.com/OasisLMF/ODS_OpenResultsData/blob/master/Docs/WorkedExamples/TVAR.xlsx) | Tail value-at-risk (TVaR) EP types |
